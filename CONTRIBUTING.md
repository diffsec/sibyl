# Contributing to Sibyl

Sibyl is licensed under AGPL-3.0, and the copyright holder also offers it under commercial licenses. To keep that possible, every contribution needs a signed contributor license agreement (CLA).

1. Open an issue that describes the change before you start large work.
2. Sign the CLA. The pull request template links to it.
3. Make sure that `actionlint`, `hadolint` and `shellcheck` pass on the files that you change.
4. Make sure that `bootc container lint` passes for changes under `os/`.

The project does not accept a pull request without a signed CLA.
